## Platform/engine facts confirmed by authoritative documentation

1. **Samsung model-family:** Samsung's model table identifies 2021 UAU8000 in the Tizen 6.0 era; 2021 Tizen uses Chromium **M76**. This supports a compatibility target, **not** proof of installed firmware behavior. [Samsung model groups](https://developer.samsung.com/smarttv/develop/specifications/tv-model-groups.html); [Web engine specs](https://developer.samsung.com/smarttv/develop/specifications/web-engine-specifications.html).
2. **TV USB:** Filesystem API offers `listStorages`, removable labels, `resolve`, and `addStorageStateChangeListener`. Need appropriate `filesystem.read` privileges; filesystem private write needs appropriate write privilege. Even where the API exists, real mounted-file visibility/permissions remain unverified. [USB guide](https://developer.samsung.com/smarttv/develop/guides/data-handling/handling-usb-storages.html); [Filesystem API](https://developer.samsung.com/smarttv/develop/api-references/tizen-web-device-api-references/filesystem-api.html).
3. **TV playback:** AVPlay `open` supports **absolute local paths** and remote URIs; its state machine, async prepare, full-screen 1920×1080 video display-rect coordinate convention, letterboxing, audio/subtitle track handling, and state-specific seek rules are documented. Need real `file.toURI()` → playable URI proof. [AVPlay guide](https://developer.samsung.com/smarttv/develop/guides/multimedia/media-playback/using-avplay.html).
4. **Codec limitation:** 2021 TV chart separates model groups and decoder profiles. **DTS audio is not supported on 2021 Samsung TVs**; container suffix alone doesn't determine playability. HEVC/H.264 resolution/profile/audio/HDR combinations must be tested. [2021 video specs](https://developer.samsung.com/smarttv/develop/specifications/media-specifications/2021-tv-video-specifications.html).
5. **TV storage:** Samsung explicitly documents **5 MB** ordinary Web Storage (`localStorage`) and advises filesystem for larger amounts. Samsung's FAQ says normal power-off/app update retains data, while uninstall deletes app data; updates installed through Tizen Studio may uninstall first and thereby erase it. `wgt-private` is intended for persistent app-private files (until uninstall), `wgt-private-tmp` is volatile. **A production-like TV upgrade path must be tested**, not assumed from ordinary in-place update prose. [Web storage](https://developer.samsung.com/smarttv/develop/guides/data-handling/using-web-storage.html); [data FAQ](https://developer.samsung.com/smarttv/develop/faq/data-and-file-handling.html); [file operations](https://developer.samsung.com/smarttv/develop/guides/data-handling/managing-file-operations.html).
6. **TV subtitles:** Samsung AVPlay documents common internal/external subtitle support, external **absolute local paths**, path-setting, language selection, timing offsets. Its subtitle guide lists **SAMI `.smi`**, SMPTE-TT and DFXP (the last for Smooth Streaming); **do not assume arbitrary external SRT/VTT/ASS rendering in AVPlay**. If necessary, explicitly consent to a non-destructive converted subtitle copy and test overlay alternatives. [Samsung subtitles](https://developer.samsung.com/smarttv/develop/guides/multimedia/subtitles.html).
7. **TV remote:** standard arrow/Enter/Back recognized; extra media keys can be registered. Must test deterministic focus on the physical unit. [Remote guide](https://developer.samsung.com/smarttv/develop/guides/user-interaction/remote-control.html).
8. **TV install:** Tizen Studio, Samsung TV SDK/extensions and signed certificates required; Device Manager/developer mode needed. Samsung warns USB installation of application packages is unsupported and simulator differences are real. Certificates need developer portal account and TV DUID. Check current free access before any spending, and **do not automatically buy enrollment**. [Device setup](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html); [certificates](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/creating-certificates.html); [SDK](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html).
9. **Desktop mpv:** mpv explicitly suggests libmpv for application backends. Sample integration explains native child-window embedding versus OpenGL render API, rendering layering/input trade-offs. mpv hardware decode is configurable and varies by Windows GPU/drivers; no guaranteed acceleration. [mpv manual](https://mpv.io/manual/stable/); [mpv integration examples](https://github.com/mpv-player/mpv-examples/blob/master/libmpv/README.md). Alternative [libVLC engine/license](https://github.com/videolan/vlc/blob/master/doc/standalone/libvlc.md). This does **not** prove libmpv can render correctly beneath a Tauri WebView with desired overlays—M0 is a hard gate.
10. **Encoding licenses:** FFmpeg license depends on build flags/linked libraries: LGPL is the base, optional GPL parts alter obligations. A redistributable binary must record the **exact** build, codecs, license and notices. [FFmpeg legal](https://www.ffmpeg.org/legal.html).

## Build-versus-fallback rules

When a gate fails: **do not invent universal capability**. Evaluate alternative supported native player, local artwork import, non-destructive desktop conversion, external subtitle import or an external website handoff; document comparison, ask only if it changes an explicit product requirement or incurs cost.
